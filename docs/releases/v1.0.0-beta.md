# ContextOS v1.0.0-beta

**Local-first shared memory for AI coding agents.**

Stop re-explaining the same codebase to every agent. ContextOS is a self-hosted memory layer: Cursor, Claude Code, and humans share versioned decisions, conventions, tasks, conflicts, and handoffs — readable in a workspace UI and by machines over REST + MCP.

## Highlights

### Context compiler

- `GET /api/v1/projects/:id/context-package` ranks memory, drops superseded entries, packs into a token budget
- Workspace **Brief** tab — live preview of what agents read
- MCP: `get_brief`, `supersede_memory`, `link_memory`, `get_memory_relations`

### Onboarding

- CLI (`contextos-memory` on npm, command `contextos`): `init`, `status`, `brief`
- Landing **TokenCompare** — interactive dump vs compiled-brief token savings
- Team invites with pending email → auto-join on register
- **Viewer** role for read-only teammates

### Stack

- React 19 + Vite SPA, Fastify 5 API, Prisma/Postgres
- Session cookies + CSRF, argon2id, MCP stdio connector
- Docker Compose production path (verified on WSL2)
- EN/IT UI, Playwright e2e, 97 unit/API tests + 7 e2e

## Quickstart

```bash
git clone <repo>
cd contextos
node scripts/setup.mjs
npm run dev
```

Open http://127.0.0.1:5173 — demo `demo@contextos.dev` / `DemoPassw0rd!` — project **Atlas CLI**.

Wire agents:

```bash
npm install -g https://github.com/carlogiovannifalocco-byte/contextos-v1/releases/download/v1.0.0-beta/contextos-memory-1.0.0-beta.tgz
contextos init --api http://127.0.0.1:3010
```
